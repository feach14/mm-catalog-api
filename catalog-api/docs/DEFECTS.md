# Реестр дефектов Catalog API

**Назначение:** список подтверждённых проблем, найденных при тестировании. В идеальном состоянии файл содержит только заголовок и правила ведения.

## Правила ведения

- Один дефект — одна запись с постоянным идентификатором `DEF-###`.
- После исправления не удаляйте запись: меняйте статус на `Исправлен` и добавляйте результат ретеста.
- В `TEST_EXECUTION.md` указывайте идентификатор связанного дефекта.

## Открытые дефекты

### DEF-001 — Невозможно создать первую категорию в пустом каталоге

| Поле | Значение |
|---|---|
| Статус | Открыт, блокирующий |
| Найден | 2026-09-25 |
| Среда | Локальная DEV-сборка, пустая таблица `material_categories` |
| Затрагивает | `POST /api/materials/categories`; последующий CRUD категорий и материалов |
| Предусловие | В каталоге отсутствуют категории |
| Шаги воспроизведения | 1. Авторизоваться менеджером. 2. Отправить валидное тело категории в `POST /api/materials/categories`. |
| Фактический результат | `500 Internal Server Error`. Повторяется на каждой попытке. |
| Ожидаемый результат | `200 OK`, возвращён id первой созданной категории, `OrderByCol` получает начальное значение. |
| Предполагаемая причина | В `CreateMaterialCategoryCommandHandler` следующий `OrderByCol` вычисляется через `MaxAsync` без обработки пустой коллекции. |
| Ретест | Не выполнен. |
