# Результат последней целевой проверки

Дата: 05.11.2026. Область: синхронизация ЛДСП и ЛМДФ любой толщины со Стройдвором и проверка совпадения справочного типа. Полный регресс не выполнялся.

## Окружение

Catalog API — `https://debug.feach.ru:5005`, Catalog Front внутри MM Admin Shell — `https://admin.debug.feach.ru:6001/catalog`. Роль «Тестер». Основное подключение и Data Protection используют только `mm-debug`.

## Результаты

- Успешно: `dotnet build catalog-api/catalog-api.slnx --no-restore`, 0 ошибок и предупреждений.
- Успешно: `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore`.
- Успешно: 181 целевая проверка реальных классов области допустимости, парсера и проверки результата синхронизации во временном harness без БД и сети. Проверены ЛДСП/ЛМДФ, точные русские и латинские обозначения, отсутствие синонима МДФ, выбор типа из основного h1 независимо от breadcrumbs и сопутствующих товаров, допустимые производители/форматы и поворот листа. Снято ограничение 16 мм; проверены дробные толщины, 22 мм и 100 мм, несовпадения типа в обе стороны и физических характеристик. Временный harness удалён.
- Успешно: `npm run build` Catalog Front; два штатных предупреждения Webpack о размере сборки.
- Успешно через UI: создана новая тестовая категория вне прежнего списка categoryId. Материал ЛМДФ 18 мм, Egger, 2800×2070, товар Стройдвора 23337 сохранился и синхронизировался с HTTP 200. Получены цена, артикул и дата; отсутствие товара отображено как «Нет в наличии», без ошибки синхронизации.
- Успешно через UI: ЛДСП 18 мм с товаром 14133 синхронизировался с HTTP 200, ценой, артикулом, датой и наличием.
- Успешно через UI: наш ЛДСП с товаром ЛМДФ 23337 и наш ЛМДФ с товаром ЛДСП 14133 возвращают HTTP 400 ProblemDetails. Сообщения содержат оба типа и видны в общей области и строке материала. Цена поставщика стала 0, дата очищена; собственная цена не изменилась.
- Успешно через UI: наш ЛДСП 16 мм с товаром ЛДСП 18 мм 14133 возвращает HTTP 400 с сообщением о несовпадении толщины; сообщение видно в общей области и строке. HTTP-статусы всех пяти UI-синхронизаций подтверждены журналом API.

## Данные и ограничения

Все тестовые записи созданы, изменены и удалены через UI тестером. Временный материал 1714 и категория с маркером `ui-regression-20261105-115502-stroydvor-scope` удалены; поиск материала вернул 0 строк, категория отсутствует в справочнике. История тестером не создавалась.

По отдельной просьбе пользователя в `mm-debug` оставлен постоянный справочный тип «ЛМДФ», id 26, `hideOnSite = false`. Он не сопоставляется с «МДФ». Рабочие материалы не менялись.

Временная недоступность PostgreSQL завершилась до UI-прогона. После восстановления актуальная сборка Catalog API запущена на свободном порту 5005; основные локальные сервисы оставлены включёнными. Постоянные настройки и staging сохранены. Миграции для изменения правила не требуются и не применялись.
