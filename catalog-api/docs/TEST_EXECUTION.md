## Результаты

- Успешно: `dotnet build catalog-api/catalog-api.slnx --no-restore`, 0 ошибок и предупреждений; `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore`.
- Успешно: `npm run build` Catalog Front.
- Успешно через UI: создание маркировки `codex-desc-20261106-f7c9` с многострочным описанием и символами `<ЛДСП> &`, повторное открытие, очистка и сохранение описания, повторное открытие с пустым описанием и восстановление текста.
- Успешно через UI: маркировка назначена связи временной кромки с материалом 41 в интерфейсе «Связь кромок с материалами»; после сохранения в обратном интерфейсе «Связь материалов с кромками» подтверждены выбранная маркировка и описание под её названием.
- Успешно: проверка OpenAPI — `RelationMarkingModel.description` допускает null и не обязателен; `RelationMarkingDto.description` и `RelationMarkingOptionDto.description` допускают null и присутствуют в обязательных полях ответа. Ограничение длины задаётся FluentValidation; `maxLength` в OpenAPI не генерируется, как и у других полей с этой валидацией.

## Данные и ограничения

Проверялся целевой пользовательский сценарий, а не полное покрытие API. Отклонение описания длиной 2001 символ и другие границы длины отдельным запросом не проверялись.
