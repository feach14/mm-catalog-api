# Результат целевой проверки синхронизации со Стройдвором

Дата: 23 ноября 2026 года. Полный регресс не выполнялся.

## Изменение

Неуспешное чтение или проверка карточки материала либо кромки сохраняет прежние
цену, артикул, наличие и дату последней успешной синхронизации. Пакетный результат
возвращает ошибку и текущий сохранённый снимок. Отказ не создаёт Update в истории;
причина остаётся в журнале. Одиночные и фоновые операции используют те же обработчики.
Отсутствие записывается только после успешного чтения корректной карточки.

## Проверки

- `dotnet build catalog-api/catalog-api.slnx --no-restore`: ошибок и предупреждений нет.
- `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore`: успешно.
- 28 целевых проверок реальных обработчиков во временном консольном стенде вне репозитория прошли.
  Использованы SQLite `:memory:` и HTTP-заглушка; обращения к реальным БД и Стройдвору отсутствовали.
- Для материалов и кромок проверены HTTP 404/503, сетевой сбой, тайм-аут, обрыв чтения,
  некорректный HTML, неизвестное наличие и ошибка проверки характеристик/единицы продажи.
  При каждом отказе снимок в БД и ответе сохраняется, включая исходное наличие true и false.
- Успешные карточки обновляют цену, артикул и дату; подтверждённое наличие и отсутствие
  меняют признак склада. Нулевые остатки всех указанных складов подтверждают отсутствие.
- Смешанные пакеты обновляют только успешные позиции. Одиночный отказ возвращает 400;
  записи истории создаются только для успешных обновлений. Отмена запроса сохраняет состояние.
- Конкурентное изменение снимка во время неудачного чтения сохраняется; результат содержит
  актуальные данные из БД, а не снимок на момент начала запроса.
- `git diff --check` прошёл. В отслеживаемых текстовых файлах проверены UTF-8 без BOM и LF.

## Локальный сервис

Catalog API пересобран и перезапущен на прежнем порту 5005 после проверки принадлежности
процесса и освобождения порта. Подключения данных и Data Protection проверены: только
`mm-debug`. Сохранены прежние параметры запуска и cookie. Старт актуальной сборки подтверждён
журналом и прослушиванием порта; сервис оставлен работающим.
Функциональный HTTP-прогон через работающий API не выполнялся.
