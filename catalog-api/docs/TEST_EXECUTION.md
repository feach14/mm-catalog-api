Жёсткий перечень допустимых форматов и ограничение производителей отсутствуют; проверка типа и толщины сохранена.

- В собственной вкладке IAB под разрешённым тестовым менеджером mm-debug создан скрытый на сайте и в ЛК материал `codex-format-match-20261121`, id 1751: ХДФ, производитель «Прочее», толщина 3 мм, формат 2800×2070, собственная цена 100, Id товара Стройдвора 16801.
- При совпадении формата `POST /api/for-admin/materials/1751/stroydvor/sync` вернул HTTP 200: цена 1056, артикул КА008155, наличие true, дата синхронизации заполнена. Значения показаны в UI.
- Через редактор формат тестового материала изменён на 2800×1220. Привязка сохранилась без ограничения по списку форматов.
- Повторная синхронизация вернула HTTP 400 с сообщением о несовпадении формата нашего материала и Стройдвора. В журнале указаны обе величины: 2800×1220 и 2800×2070.
