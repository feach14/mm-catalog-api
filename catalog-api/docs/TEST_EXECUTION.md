# Последний прогон: переименование групп и маршрутов CatalogAPI

Дата: 08.10.2026. Область: `DOC-05`, адресные проверки авторизации и валидации.

## Окружение

Собственный временный CatalogAPI: `https://catalog-api.debug.feach.ru:5015`, другой порт ранее разрешён пользователем. Процесс пользователя на `5005` не использовался и не останавливался. Авторизация тестера и обычного пользователя — через `https://accounts-api.debug.feach.ru:5003`.

Для тестового процесса CatalogAPI подключение через переменную окружения согласовано с DEV-БД AccountsAPI, чтобы использовать общие ключи cookie. Постоянные настройки не менялись, миграции не применялись.

Инструмент: адресные HTTP-запросы через функции существующего `catalog-api/http_regression_runner.py`. Полный регресс не выполнялся.

## Результат

| Проверка | Результат |
|---|---|
| OpenAPI | Все восемь переименованных групп имеют суффикс `ForAdmin` или `ForCalculate`. Пути используют `/api/for-admin/...` и `/api/for-calculate/...`; старых префиксов нет. `CategoryId` по-прежнему отмечен как `required`. Очистка тестовой истории скрыта из схемы |
| Административные маршруты | Списки материалов, пяти справочников и истории: тестер — `200`, без cookie — `401`, обычный пользователь — `403` |
| Маршруты для Calculate | Категории и материалы существующей категории: тестер — `200`, без cookie — `401`, обычный пользователь — `403` |
| Старые маршруты | Все девять проверенных адресов чтения с прежними префиксами возвращают `404` |
| Валидация категории | Отсутствующий и нулевой `categoryId` возвращают `400` в формате ProblemDetails |
| Публичный контракт | `/api/materials` и `/api/materials/material-types` возвращают `200` без cookie |
| Очистка истории | Новый маршрут без cookie возвращает `401`; удаление данных не выполнялось |

Сборка CatalogAPI прошла: 0 ошибок и предупреждений. Проверка форматирования изменённых контроллеров, синтаксис HTTP-раннера и `git diff --check` прошли. Общая обязательная проверка `dotnet format` обнаружила прежнюю ошибку `WHITESPACE` в `core/AccountAuth/AuthConstants.cs:5`; подмодуль не менялся.

Catalog Front переведён на новые маршруты; `npm run build` прошёл с двумя предупреждениями Webpack о размере сборки. UI-проверка remote внутри Shell не выполнена: инструмент сообщил, что встроенный браузер IAB недоступен.

Тестовые сущности не создавались, данные не изменялись. Собственный CatalogAPI остановлен, временные файлы удалены.
