## Исправления

- Публичное чтение материала для Calculate больше не наследует описание `401/403` защищённых методов.
- В административных ответах `403` учтена разрешённая роль тестера; успешный ответ истории имеет русское описание.
- У скрытого удаления тестовой истории убрано перекрытие общей схемы `400` ответом без тела.
- Для выдачи изображения документирован фактически возможный `412`.
- Описание назначения изображения задано на enum и теперь попадает в multipart-схему. Описание самого файла уже передаётся обновлённым Core; дубли регистрации OpenAPI отсутствуют.

Исходники Core, staging, настройки запуска и данные БД не изменялись. Временный стенд удалён; собственные серверные процессы не создавались.
