# Отчёт о проверке Catalog API

Дата: 20.10.2026.

Область: короткие имена 16 полей отдельного компактного endpoint материалов, размер ответа на реальных данных и использование кеша во фронте. Выполнены целевые проверки DOC-07/08/09, MAT-03D/MAT-03E; полный регресс не запускался.

Окружение: локальный Catalog API `https://catalog-api.debug.feach.ru:5005`, текущая сборка с `/api/for-admin/materials/compact`; 1150 реальных материалов из настроенной БД `mm`. Авторизация через локальный Accounts API и роль tester из DEV-контура. Для процесса Catalog временно согласованы домен cookie и отдельное хранилище ключей Data Protection с DEV Accounts (`mm-debug`). Постоянные настройки не изменялись. Все обращения проверки к Catalog — GET; материалы и справочники не изменялись.

## Размеры ответа

Размеры указаны в байтах тела HTTP-ответа, без заголовков. Обычный форматированный ответ — 1 033 377 байт. Новая компактная выдача измерена через HTTP. Для сравнения прежние имена полей восстановлены на тех же данных и сжаты тем же .NET Brotli/gzip с уровнем Fastest; обратное преобразование новой выдачи и её локальное сжатие побайтово совпали с HTTP.

| Compact | Прежние имена, байт | Короткие имена, байт | Экономия |
|---|---:|---:|---:|
| Без сжатия | 334 552 | 218 402 | 116 150 (34,72%) |
| gzip | 47 052 | 44 637 | 2 415 (5,13%) |
| Brotli | 32 480 | 31 455 | 1 025 (3,16%) |

Имена полей элементов: `i,n,a,s,m,t,th,c,q,o,p,h,hp,cu,pv,en`. Контейнер и фильтры сохраняют обычные имена. Brotli уменьшает передаваемое тело на 96,96% относительно обычной выдачи. Скорость запросов отдельно не сравнивалась.

## Результаты

- Все варианты вернули HTTP 200 и `application/json; charset=utf-8`.
- Распакованные gzip и Brotli побайтово совпали с компактной выдачей без сжатия; `Vary` содержит `Accept-Encoding`.
- Все 16 полей каждого материала совпали с проекцией обычного списка; порядок элементов и все фильтры совпали.
- Фильтры: 15 категорий, 10 производителей, 4 типа, 10 толщин, 6 форматов плит.
- У compact нет форматирующих переносов. Обычный endpoint сохранил форматирование и остался без сжатия даже при `Accept-Encoding: br`; глобальный `WriteIndented` включён.
- Сборка API завершилась без предупреждений и ошибок; `dotnet format --verify-no-changes --no-restore` для solution прошёл. Синтаксис HTTP runner проверен.
- OpenAPI DOC-07/08/09 подтвердили имена, порядок, типы и обязательность всех 16 полей; русские описания сохранены.
- Класс сжатия находится в `Catalog.Api/Extensions`, namespace `Catalog.Api.Extensions`.

## Проверка вместе с фронтом

Проверено во встроенном браузере Codex внутри локального Admin Shell. Измерительные HTTP-запросы завершены до UI-сценария. Запросы считались по журналу локального Catalog API отдельно для `/api/for-admin/materials/compact` и `/api/for-admin/materials/thicknesses`; параллельные запросы других маршрутов не относятся к этому сценарию.

| Действие | Наблюдение API | Результат интерфейса |
|---|---|---|
| Полная загрузка материалов | 1 GET compact, HTTP 200 | 1150 строк; «Показано 1150 из 1150» |
| Переход на толщины | Зафиксирован GET thicknesses, HTTP 200 | 10 записей толщин |
| Возврат на материалы | 0 новых GET compact и thicknesses; полный захват журнала | 1150 строк, тексты всех строк совпали с исходными |

Вывод журнала за переход на толщины был усечён инструментом из-за параллельного трафика; точное число всех запросов в этом промежутке не утверждается. Захват первой загрузки и возврата полный. Повторного запроса материалов при возврате нет.

Ошибок и предупреждений в консоли браузера за сценарий нет. Сборка Front и 11 целевых тестов прошли. Материалы не создавались, не редактировались и не удалялись. Секреты и тела ответов в отчёт не включены.

Все четыре временных сервиса остановлены; временные тела ответов и скрипты удалены. Сохранены только обезличенные метаданные замеров и снимок интерфейса.
