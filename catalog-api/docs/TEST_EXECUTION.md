# Журнал прогонов Catalog API

**Назначение:** результаты конкретных прогонов тест-кейсов из `TEST_CASES.md`. Добавляйте новый раздел для каждого прогона; не изменяйте историю завершённых прогонов.

## Статусы

- `Пройден` — фактический результат соответствует ожидаемому.
- `Не пройден` — сценарий выполнен, но результат отличается от ожидаемого.
- `Заблокирован` — сценарий нельзя выполнить из-за внешней причины или известного дефекта.
- `Не начат` — сценарий ещё не выполнялся.
- `Отменён` — сценарий намеренно исключён из прогона.
