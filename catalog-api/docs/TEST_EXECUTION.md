# Результат целевой проверки клиентских цен и процентов

Дата: 26 ноября 2026 года. Полный регресс не выполнялся.

Проверены актуальные Catalog API (`https://catalog-api.debug.feach.ru:5005`)
и Calculate API (`https://calculate-api.debug.feach.ru:5006`). Данные и ключи
Data Protection используют `mm-debug`. Вход выполнен тестовым менеджером
по разрешению пользователя; после входа выполнялись только GET. Cookie и секреты
не сохранялись. Данные каталога и настройки Calculate не изменялись.

- В compact проверены 1062 активных материала (544 с ручной базой, 518 с ценой
  поставщика) и 123 архивных (105 и 18 соответственно). Для каждой группы
  проверена карточка: всего четыре карточки, значения совпадают с compact.
  Фактические проценты Calculate — 10/0/0 для частного/оптового/индивидуального
  клиента. Все три процента и три суммы верны, дробные суммы не округляются.
- В compact проверены 410 кромок: 135 толщиной 0.4 мм, 138 толщиной 1 мм,
  137 толщиной 2 мм. Проверена одна карточка каждой толщины. Все три цены и
  процента совпадают с Calculate и compact; текущие наценки всех трёх групп — 0%.
  В имеющихся данных кромок представлены только Meter и ручная база цены.
- Временная проверка .NET без БД подтвердила ненулевые наценки всех трёх толщин,
  приоритет положительной цены поставщика, ручную базу при нулевой/отрицательной
  цене поставщика, отсутствие округления, нулевую базу и null для неизвестной
  толщины. Проверены обязательные поля внешнего JSON, один анонимный GET по
  настроенному пути, null при 503/504/5xx и сохранение ошибок 401, некорректного
  успешного ответа и отмены. Временные файлы удалены.
- Live OpenAPI: MaterialClientPricesDto и EdgeClientPricesDto содержат ровно
  шесть обязательных полей — три числовые цены и три целочисленных процента,
  все с русскими описаниями. clientPrices обязателен и допускает null во всех
  восьми использующих его DTO материалов и кромок.
- Сборка с `--no-restore` и `dotnet format --verify-no-changes --no-restore`
  прошли; затронутые сервисы пересобраны и перезапущены. Семь изменённых/новых
  C# файлов проверены на UTF-8 без BOM, LF и отсутствие завершающего LF.
  Проверка синтаксиса изменённого Python-раннера и `git diff --check` прошли.
- Catalog Front проверен в IAB на актуальной сборке: материалы и кромки,
  настольная и мобильная ширина. Проценты отображаются рядом с клиентскими ценами.

Live-проверка не покрывает Roll, положительную цену поставщика у кромок и
неподдерживаемую толщину: таких записей в текущем каталоге нет. Настройки и данные
для расширения покрытия не менялись. Сервисы оставлены запущенными.
