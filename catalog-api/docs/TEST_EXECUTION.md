# Результат целевой проверки полных названий в ошибках

Дата: 19 ноября 2026 года. Проверена обновлённая локальная сборка Catalog API на `https://catalog-api.debug.feach.ru:5005`; данные и ключи Data Protection — только `mm-debug`. Запросы отправлялись с `Origin: https://debug.feach.ru`.

## Целевые HTTP-проверки

Использован отдельный тестовый менеджер `mm-debug`, поскольку исторический тестер недоступен. Проверки ролей в этот прогон не входят. Созданы собственные скрытый материал и две кромки; существующие справочники только читались. Полный регресс не запускался.

| Сценарий | Результат |
|---|---|
| Нет кромки активного материала, без маркировки | HTTP 400: Id и полное имя материала в формате ЛК |
| Нет кромки активного материала, `forVek=true` | HTTP 400: полное имя и маркировка «Век ЛК» |
| Синхронизация материала без привязки | HTTP 400: полное имя и причина отказа |
| Нет кромки архивного материала, без маркировки | HTTP 400: то же полное имя после архивирования |
| Нет кромки архивного материала, `forVek=true` | HTTP 400: полное имя и маркировка «Век ЛК» |
| Синхронизация складской кромки без привязки | HTTP 400: название, размер и суффикс «(Склад)» |
| Синхронизация заказной кромки без привязки | HTTP 400: название и размер, без складского суффикса |
| Несколько подходящих кромок | HTTP 400: Id, полное имя материала и причина неоднозначности |
| Удаление связанной кромки | HTTP 400: Id, полное имя кромки и требование снять связи |

Все 9 сценариев пройдены. Полное имя материала дополнительно сверено с `GET /api/for-calculate/materials/{id}`. Проверены записи локального лога: пять ошибок подбора кромки, одна ошибка синхронизации материала и две ошибки синхронизации кромок содержат полные названия.

Внешние запросы к Стройдвору, фоновые задания и конкурентные изменения данных не запускались; эти ветки проверены чтением кода.
