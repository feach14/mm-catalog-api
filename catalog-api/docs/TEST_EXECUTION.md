# Последний прогон: контракт материалов для CalculateAPI

Дата: 08.10.2026. .NET SDK 10.0.401. Область: `CALC-01—CALC-06`.

## Окружение

Собственный временный CatalogAPI: `https://catalog-api.debug.feach.ru:5015`. Другой порт явно разрешён пользователем, поскольку `5005` занят посторонним процессом. Авторизация тестера и обычного пользователя — через `https://accounts-api.debug.feach.ru:5003`.

Для тестового процесса CatalogAPI подключение через переменную окружения согласовано с DEV-БД AccountsAPI. Постоянные настройки не менялись. Исходные конфигурации Development используют разные БД ключей cookie, что даёт `401` при межсервисной авторизации; в БД из конфигурации CatalogAPI также отсутствует поле Accounts `is_tester`. Миграции для подготовки окружения не применялись.

Инструмент: временный адресный HTTP-сценарий на основе функций существующего `catalog-api/http_regression_runner.py`. Полный регресс не выполнялся.

- Сборка решения прошла: 0 ошибок, 0 предупреждений.
- Обязательная общая проверка `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore` обнаружила только ранее существовавший `WHITESPACE` в `core/AccountAuth/AuthConstants.cs:5`. Подмодуль не изменён. Отдельная проверка трёх изменённых C#-файлов через `--include` прошла.
- Проверены 197 отслеживаемых текстовых файлов основного репозитория и `core`: UTF-8 без BOM, LF, без конечного перевода строки. `git diff --check` не выявил нарушений.
