# Результат целевой проверки комментариев материалов

Дата: 20 ноября 2026 года. Проверены изменения Catalog API для внутренних комментариев
менеджеров; целевой контур — `mm-debug`.

- `dotnet build catalog-api/catalog-api.slnx --no-restore` — успешно, предупреждений и ошибок нет.
- `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore` — успешно.
- `git diff --check` — успешно.
- Создана инструментом EF Core миграция `20261120151318_AddMaterialManagerComments`;
  она создаёт только таблицу комментариев, индексы и каскадные связи владельца.
  Существующие материалы не меняются; перед созданием проверена read-only история `mm-debug`:
  предыдущая миграция `20261119164550_AddEdgeStroydvorSynchronization` применена.
- Миграция к БД агентом не применялась: согласно `AGENTS.md` её применяет пользователь вручную.
  До применения функциональные сценарии `MATERIAL-COMMENT-01..07` заблокированы.
- Полный регресс не запускался; тестовые записи backend-проверками не создавались.
- После сборки API запущен на свободном локальном порту `5005` в Development с БД данных
  и ключей `mm-debug`, cookie-доменом `.debug.feach.ru`. Для проверки используется
  `https://debug.feach.ru:5005`: `catalog-api.debug.feach.ru` разрешается во внешний IP;
  `hosts` и постоянная конфигурация не менялись.
- `/swagger/v1/swagger.json` — HTTP 200: POST/DELETE комментариев объявляют типизированный
  ответ 200; `MaterialCommentDto` требует `id` и `text`, входная модель требует `text`.
  Поле `comments` присутствует только в административных схемах материалов.
- Без авторизации POST комментария возвращает 401. После входа отдельным тестовым
  менеджером `mm-debug` пустой текст, пробелы и 51 символ возвращают 400 с ошибкой поля
  `text`. Запрос с 50 символами проходит проверку длины и для неизвестного материала
  возвращает 400 «Материал не найден». Записи не создавались.
- Тестер из служебного файла отсутствует в текущей `mm-debug`; использован разрешённый
  резервный тестовый менеджер. Проверки прав именно тестера не выполнялись.
- В IAB открыт прямой URL Shell `https://admin.debug.feach.ru:6001/catalog/materials`:
  авторизация и mount каталога успешны, показана одна шапка. Загрузка списка возвращает
  ошибку до ручного применения миграции; сохранение, удаление, архив и восстановление
  комментариев через настоящий UI пока не проверены.
