# Последний прогон: уникальность через FluentValidation

Дата: 08.10.2026. Область: проверки уникальности толщин и размеров плит при создании и обновлении; полный регресс не выполнялся.

## Окружение

Собственный CatalogAPI: `https://catalog-api.debug.feach.ru:5015`, временный порт ранее разрешён пользователем. Cookie тестера получена через AccountsAPI на `5003`. Подключение тестового процесса через переменную окружения согласовано с DEV-БД AccountsAPI для общих ключей cookie; постоянные настройки не менялись, миграции не применялись.

Адресные HTTP-запросы выполнены через функции существующего `catalog-api/http_regression_runner.py`. Префикс тестовых данных: `codex-unique-fa875dab6aad4db6`.

## Результаты

| Проверка | Результат |
|---|---|
| Толщина: повтор значения в POST и PUT | `400` ProblemDetails с русским сообщением в `errors.value` |
| Размер плиты: повтор названия в POST и PUT | `400` ProblemDetails с русским сообщением в `errors.name` |
| Размер плиты: повтор пары высота/ширина в POST и PUT | `400` ProblemDetails с русским сообщением в `errors.width` |
| Отказ при обновлении | Повторный GET подтверждает отсутствие изменений |
| Отказ при создании | Дополнительные записи не создаются |
| Исключение текущей записи | Повторное сохранение и переименование с прежними уникальными значениями возвращают `200` для обоих справочников |
| Изменение уникальных значений | Новое значение толщины и новая пара размеров сохраняются; последующий дубль отклоняется |
| Базовая валидация | Нулевая, отрицательная и излишне точная толщина, нулевые размеры возвращают ошибки полей |
| История | Действия тестера не создали событий по префиксу |

Сборка CatalogAPI: 0 ошибок и предупреждений. Полная проверка `dotnet format catalog-api/catalog-api.slnx --verify-no-changes --no-restore`, синтаксис HTTP-раннера, `git diff --check` и проверка кодировки прошли. Стабильные сценарии `SIZE-03`, `SIZE-03A`, `SIZE-03B`, `SIZE-04` и `THICK-03` уточнены; проверки ошибок полей и дублей при обновлении добавлены в существующий раннер.

Все четыре тестовые записи удалены, отсутствие данных и истории по префиксу подтверждено. Собственный процесс CatalogAPI остановлен, временный лог удалён. Подтверждённых дефектов в затронутом поведении не найдено.
