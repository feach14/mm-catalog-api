# Ручная синхронизация кромок со Стройдвором

Перед запуском обновлённых API и Catalog Front пользователь применяет миграцию
`20261119164550_AddEdgeStroydvorSynchronization`. Она добавляет в `catalog.edges`
nullable-поля `stroydvor_product_id`, `stroydvor_article`, `stroydvor_last_sync_at`,
цену `stroydvor_price numeric(18,2)` с начальным значением `0`, наличие
`stroydvor_in_stock=false` и индекс по Id поставщика. Существующие кромки, ручные
цены и связи не меняются. Откат удаляет только новые данные поставщика.

## Привязка и снимок

Создание и изменение кромки принимают `stroydvorProductId`: положительное число
привязывает товар, `null` удаляет привязку. Если поле отсутствует при обновлении,
прежняя привязка сохраняется. Сохранение кромки само не обращается к поставщику.
Ограничений на производителя или размер для ручной привязки нет.

Карточка и `/api/for-admin/edges/compact` возвращают `stroydvorProductId`,
`stroydvorArticle`, `stroydvorPrice`, `stroydvorLastSyncAt`, `stroydvorInStock`.
Ручная `price` остаётся отдельной ценой. Поля поставщика доступны также для
Excel-выгрузки вместе со `stroydvorUrl`.

Изменение Id поставщика, названия, артикула, производителя или единицы продажи
очищает снимок поставщика. Изменение типа/длины единицы продажи также очищает
снимки связанных кромок. Новую цену после этого получают ручной синхронизацией.
Изменение размера кромки или его толщины/ширины в справочнике не сбрасывает цену.

## Запуск

- `POST /api/for-admin/edges/{id}/stroydvor/sync` без тела обновляет одну кромку.
- `POST /api/for-admin/edges/stroydvor/sync` с `{ "ids": [1, 2] }` обновляет
  от 1 до 100 различных привязанных кромок; ответ — `{ "items": [...] }`.

Один результат содержит `edgeId`, `success`, `error`, пять полей снимка и
`stroydvorUrl`. Успешный одиночный запрос возвращает `200`; ошибка поставщика —
`400 ProblemDetails` без изменения прежних цены, артикула, даты и наличия.
Это относится к сетевым сбоям, тайм-аутам, HTTP-ошибкам и ошибкам чтения или проверки
карточки. Пакетный запрос возвращает для ошибки `success=false`, причину и текущий
сохранённый снимок. Отсутствие записывается только после успешного чтения и проверки
карточки с явным отсутствием или нулевыми остатками всех указанных складов;
неизвестное наличие считается ошибкой. Пакетный запрос возвращает результаты каждого
товара; неизвестные Id или отсутствие привязки отклоняют весь запрос до чтения
поставщика. Изменение кромки, привязки, единицы продажи или снимка во
время внешнего запроса не позволяет записать устаревший результат.

Успешная синхронизация записывает историю кромки по обычным правилам каталога;
ошибки остаются в журнале и не создают запись об изменении снимка. Фоновая
служба и расписание материалов кромки не обрабатывают. Автосинхронизации кромок
и автоматического подбора привязок нет.

## Проверка товара и единиц цены

Читается только основная карточка `https://stroydvor21.ru/products/{id}`.
Заголовок должен начинаться отдельным словом «Кромка»; ЛДСП/ЛМДФ, неизвестные
единицы цены и нерублёвая валюта отклоняются. Толщина и ширина не проверяются:
они могут отличаться от наших размеров и расходиться внутри карточки поставщика.
Блоки похожих товаров не участвуют в чтении цены и характеристик.

Цена за погонный метр сохраняется напрямую для `Meter`, а для `Roll` умножается
на длину нашей бухты. Цена за бухту поставщика сначала делится на явно указанную
длину его бухты; без этой длины синхронизация отклоняется. Длина читается только
для цены за бухту: сначала из характеристик, затем из названия, без сопоставления
разных источников. Для цены за метр размеры и длина поставщика не используются. Полученную цену метра
умножают на длину нашей бухты для `Roll`. `stroydvorPrice` всегда хранится в
единице нашей продажи, с округлением до копеек от середины вверх. Кратность
отреза при `Meter` не умножает цену метра. Недопустимая стоимость отклоняется.

В `/api/for-calculate/edges/price` положительная `stroydvorPrice` заменяет ручную
`price`, иначе возвращается ручная цена. Наличие поставщика не меняет это
правило, собственные складской признак и остаток не подменяются. Ранее
сохранённые расчёты сами не пересчитываются.
