# План тестирования Catalog API

**Статус документа:** активный.  
**Последнее обновление:** 2026-09-25.  
**Назначение:** единый живой план ручной проверки Catalog API. В новых чатах этот файл следует прочитать перед продолжением тестирования и обновлять по мере выполнения, изменения или отмены сценариев.

## Правила ведения

- Отмечайте завершённый сценарий в таблице результатов: `Не начат` → `Пройден`, `Не пройден`, `Заблокирован` или `Отменён`.
- Не храните в документе пароли, значения cookie, токены и иные секреты.
- Если API или ожидаемое поведение изменилось, обновите соответствующий сценарий и добавьте запись в журнал изменений.
- Все созданные тестовые сущности нужно удалить в разделе «Завершение».

## Контекст API

- API каталога: локальный проект `Catalog.Api`.
- Авторизация: cookie `AccountsApiCookie`.
- Авторизация менеджера выполняется через Accounts API: `POST /api/sign/in`.
- Публичные методы не требуют cookie; админские операции и изменение данных требуют cookie менеджера.

## 3. CRUD категорий

### Тестовые данные

Создать три категории с уникальными названиями, например `API TEST Category 1`, `API TEST Category 2`, `API TEST Category 3`. Зафиксировать их id в журнале результатов.

| ID | Сценарий | Шаги | Ожидаемый результат | Статус | Фактический результат |
|---|---|---|---|---|---|
| CAT-01 | Создание трёх категорий | Трижды вызвать `POST /api/materials/categories` | Все запросы успешны, получены id категорий | Не начат | |
| CAT-02 | Получение списка | Вызвать `GET /api/materials/categories` | Созданные категории есть в списке; порядок соответствует `OrderByCol` | Не начат | |
| CAT-03 | Получение по id | Вызвать `GET /api/materials/categories/{id}` для каждой категории | Данные соответствуют созданным | Не начат | |
| CAT-04 | Обновление средней категории | Вызвать `PUT /api/materials/categories/{id}` | Изменения видны в повторном `GET` | Не начат | |
| CAT-05 | Перемещение средней вверх | Изменить сортировку средней категории вверх | Средняя категория меняется местами с первой | Не начат | |
| CAT-06 | Перемещение средней вниз | Изменить сортировку категории вниз | Категория меняется местами со следующей | Не начат | |
| CAT-07 | Верхняя граница сортировки | Попытаться поднять первую категорию | Бизнесовая ошибка: выше перемещать некуда | Не начат | |
| CAT-08 | Нижняя граница сортировки | Попытаться опустить последнюю категорию | Бизнесовая ошибка: ниже перемещать некуда | Не начат | |
| CAT-09 | Удаление используемой категории | Создать материал в тестовой категории; вызвать `DELETE /api/materials/categories/{id}` | Удаление отклонено; категория и материал сохранены | Не начат | |
| CAT-10 | Удаление свободной категории | Удалить привязанный материал, затем категорию | Категория удалена и отсутствует в списке | Не начат | |

## 4. CRUD материалов

### Тестовые данные

Использовать минимум две тестовые категории. В первой создать не менее двух материалов для проверки сортировки, во второй — минимум один материал для проверки изоляции категорий.

| ID | Сценарий | Шаги | Ожидаемый результат | Статус | Фактический результат |
|---|---|---|---|---|---|
| MAT-01 | Создание материалов | Создать минимум три материала в двух категориях | Успех; получены id материалов | Не начат | |
| MAT-02 | Публичная и админская выдача | Проверить `GET /api/materials`, `/api/materials/{id}`, `/api/materials/admin`, `/api/materials/admin/{id}` | Материалы видны в соответствующих выдачах | Не начат | |
| MAT-03 | Фильтры публичного списка | Проверить `raskroy`, `pvhFacades`, `emalFacades` | Возвращаются только применимые материалы | Не начат | |
| MAT-04 | Обновление материала | Вызвать `PUT /api/materials/{id}` и изменить поля | Обновлены название, артикул, размеры, цена, количество, флаги, категория, ссылка и единица измерения | Не начат | |
| MAT-05 | Проверка после обновления | Повторить публичный и админский `GET` | Отображаются обновлённые значения | Не начат | |
| MAT-06 | Сортировка в категории | Переместить материал среди материалов той же категории | Порядок изменён только внутри этой категории | Не начат | |
| MAT-07 | Изоляция сортировки | Сверить порядок материалов второй категории | Порядок второй категории не изменился | Не начат | |
| MAT-08 | Границы сортировки | Поднять первый и опустить последний материал | В обоих случаях бизнесовая ошибка | Не начат | |
| MAT-09 | Удаление материала | Вызвать `DELETE /api/materials/{id}` | Успех; материал отсутствует в публичной и админской выдаче | Не начат | |
| MAT-10 | Повторное удаление | Ещё раз удалить уже удалённый материал | Корректная ошибка API | Не начат | |
