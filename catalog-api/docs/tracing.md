# Трассировка запросов

ASP.NET Core и `HttpClient` передают контекст W3C через `traceparent`. Общий для цепочки вызовов `TraceId` состоит из 32 шестнадцатеричных символов. `SpanId` обозначает отдельную операцию, `ParentId` связывает её с родительской, а `RequestId` относится к конкретному входящему HTTP-запросу. Эти локальные идентификаторы не заменяются общим TraceId.

`Microsoft.Extensions.Logging` добавляет идентификаторы текущей Activity в scopes автоматически. В Development включён вывод scopes в консоль. Для поиска всей цепочки используют поле `TraceId`; поле `traceId` в ProblemDetails содержит то же значение, включая ошибки FluentValidation, MVC binding и общего обработчика исключений.

## Стабильные тест-кейсы

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| TRACE-01 | HTTP-вызов другого сервиса с корректным входящим `traceparent` | Оба сервиса и исходящий HttpClient сохраняют входящий TraceId; scopes соответствуют текущей Activity; SpanId и RequestId разных входящих запросов различаются |
| TRACE-02 | Цепочка без входящего `traceparent` | Создаётся валидный TraceId, одинаковый в логах обоих сервисов |
| TRACE-03 | Несколько параллельных цепочек | Каждая цепочка сохраняет собственный TraceId; идентификаторы соседних запросов не смешиваются |
| TRACE-04 | Некорректный входящий `traceparent` | Создаётся новый валидный TraceId; некорректное значение не попадает в идентификатор цепочки |
| TRACE-05 | Ответы 400 от FluentValidation, MVC binding и BadHttpRequestException | `traceId` ответа совпадает с 32-значным TraceId соответствующих логов; полного Activity.Id в поле нет |
| TRACE-06 | Исключение 500 и преобразованная ошибка внутреннего сервиса | ProblemDetails сохраняет TraceId всей цепочки |
| TRACE-07 | UnauthorizedAccessException с ответом 403 | Ответ содержит тот же TraceId, что и логи запроса |

Проверки общей инфраструктуры можно выполнять на изолированном HTTP-стенде без бизнес-БД. Это не заменяет проверку конкретного запущенного окружения. После изменения кода API требуется перезапуск процессов.
